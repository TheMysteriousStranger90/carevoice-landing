# CareVoice Landing

CareVoice Landing is a modern Angular landing page for the CareVoice product.

## Tech stack

- Angular 18
- TypeScript
- SCSS
- Azure Static Web Apps

## Local development

```bash
npm install
npm run dev
```

The app will be available at http://localhost:4200/.

## Production build

```bash
npm run build:prod
```
